# C++ Module 02 — École 42

Projet développé en **C++98** dans le cadre du cursus de l'école 42.

Ce module introduit la **forme canonique orthodoxe des classes**, la surcharge d'opérateurs et la représentation des nombres à virgule fixe (*fixed-point numbers*).

L'objectif est d'approfondir la programmation orientée objet et la manipulation d'objets représentant des valeurs numériques.

## Exercices

- **ex00 — My First Class in Orthodox Canonical Form :** création d'une classe `Fixed` respectant la forme canonique orthodoxe.
- **ex01 — Towards a more useful fixed-point number class :** conversion entre entiers, flottants et nombres à virgule fixe.
- **ex02 — Now we're talking :** surcharge des opérateurs arithmétiques, de comparaison et d'incrémentation/décrémentation pour manipuler les objets `Fixed`.

## Compétences mises en œuvre

- Programmation en C++98
- Programmation orientée objet
- Forme canonique orthodoxe (constructeur par défaut, constructeur de copie, opérateur d'affectation et destructeur)
- Surcharge d'opérateurs
- Constructeurs de conversion
- Gestion des nombres à virgule fixe
- Encapsulation et méthodes membres
